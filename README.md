# BuildWise AI
AI-assisted construction planning and document verification prototype.

Live demo: https://nagacharan987.github.io/BuildWise-AI/

## Current features
- Professional construction planner
- Preliminary cost and material estimates
- BuildWise AI Assistant prototype
- SHA-256 document fingerprint
- Responsive interface

## Important architecture note
The current GitHub Pages version uses a browser-based guidance prototype. A production AI model must be connected through a secure backend; API keys should never be placed in public frontend JavaScript.

## Roadmap
1. Secure AI backend
2. User accounts and project dashboard
3. Database
4. Engineer marketplace
5. Blockchain anchoring for document fingerprints
6. Location-aware construction estimates

This is an educational prototype. Qualified professionals must verify real construction decisions.
